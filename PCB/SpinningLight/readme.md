# PCB 
The PCB makes the wirering easier and allows for easy attatchment of additional sensors. The PCB was created using KiCAD 7.0 and this path includes all files to order and modify the files at hand. 

## Additional Modifications
The PCB already has lanes to multiple GPIO pins of the ESP, allowing easy modification and expansion with more sensor. Some inputs use the additional unused channels of the Level shifter.
